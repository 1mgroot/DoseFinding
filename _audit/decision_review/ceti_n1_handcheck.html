rho=0 Joint-cell Check / 条件独立四格概率核对

With rho=0, the Gumbel adjustment term is zero, so every joint cell equals the product probability.

adj = pT * pE * (1-pT) * (1-pE) * (exp(rho)-1)/(exp(rho)+1)
rho = 0 => adj = 0
P(T=t,E=e | I,d) = P(T=t | I,d) * P(E=e | I,d)

n=1 Selection Hand Calculation / n=1 候选选择手算

Because n_simulations=1, final_admissible_missing_rate can only be 0 or 1. With target range [0.80, 0.85], rate 1 has distance 0.15 and rate 0 has distance 0.80. The manual selection below reproduces the implementation rule: choose in-range least strict if possible; otherwise choose closest to the target range with the coded tie-break.

missing_count = final_admissible_missing_rate * n_simulations
distance(rate, [0.80,0.85]) = 0 if 0.80 <= rate <= 0.85
distance = 0.80 - rate if rate < 0.80
distance = rate - 0.85 if rate > 0.85
With n=1: distance(1) = 0.15, distance(0) = 0.80
